# Notes in docs/

- Frontmatter on every note: `title`, `summary` (one line, shown in the repo map), `updated`.
- Relative markdown links (`[text](other.md)`), not `[[wikilinks]]`.
- Never invent facts about the artist. Use what's in the notes, or mark it as placeholder and open a GitHub issue for it.
- Before ending a session: add a line to `log.md`, add to `decisions.md` if something was decided.
